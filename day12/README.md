## Project

### Port Service Checker

Features:

- User enters a port number
- Finds service using dictionary
- Handles invalid inputs
- Runs continuously until user enters 0

Example:

```text
Enter port: 22

22 -> SSH
```

Unknown port:

```text
Enter port: 9999

9999 -> Unknown Service
```

Exit:

```text
Enter port: 0

Goodbye!
```
