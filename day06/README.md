## Challenge

Create a program that keeps asking the user for a number.

- If the user enters `0`, the program exits.
- Otherwise, it prints the entered number and asks again.

## Example

```text
Enter number: 10
You entered: 10

Enter number: 7
You entered: 7

Enter number: 0
Goodbye
```
