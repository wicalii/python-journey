## What I Learned

In this day I learned how to create reusable code using functions.

### Function

A function is a block of code that can be called multiple times.

Example:

```python
def hello():
    print("Hello")
```

---

## Parameters

Functions can receive values:

```python
def hello(name):
    print(name)
```

---

## Return

Functions can return values:

```python
def add(a,b):
    return a+b
```
