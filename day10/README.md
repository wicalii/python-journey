## Project

Port Service Lookup Tool

The program:

- Receives a port number from the user.
- Finds the service name.
- Displays the result.
- Saves the result into `history.txt`.
- Shows the history after the program finishes.

## Example

```text
Enter port: 22
22 -> SSH

Enter port: 443
443 -> HTTPS

Enter port: 9999
9999 -> Unknown Service

Enter port: 0
Goodbye!

History:
22 -> SSH
443 -> HTTPS
9999 -> Unknown Service
```
